Test Activation and Deactivation चाचणी सक्रिय/निष्क्रिय करणे
You can only edit a test while it is inactive. चाचणी निष्क्रिय असतानाच आपण ती संपादित करू शकता.
Once test become active, it can be taken by students. चाचणी सक्रिय झाल्यावर विद्यार्थी ती देऊ शकतात.
If you manually activate a test, any existing schedule is removed. चाचणी मॅन्युअली सक्रिय केल्यास, आधीचे वेळापत्रक काढून टाकले जाईल.
Tests automatically become inactive when its test time elapses. चाचणीचा कालावधी संपल्यानंतर ती आपोआप निष्क्रिय होते.
When a test is deactivated (manually or automatically), it becomes
non‑editable.		 चाचणी निष्क्रिय झाल्यावर (मॅन्युअली किंवा आपोआप), ती संपादित करता येत नाही.
Once students have started the exam, deactivating it will not interrupt those currently taking it; however, no new students will be able to begin the exam. विद्यार्थ्यांनी परीक्षा सुरू केल्यानंतर ती निष्क्रिय केली तरी सध्या परीक्षा देत असलेल्या विद्यार्थ्यांच्या परीक्षेत व्यत्यय येणार नाही; मात्र नवीन विद्यार्थी परीक्षा सुरू करू शकणार नाहीत.
Practice Tests need not to be activated or scheduled. सराव चाचणी सक्रिय करणे आवश्यक नाही.
