{% trans 'Users and Beneficiaries' %}

{% blocktrans %}Built for institutional deployment or service based models.{% endblocktrans %}

{% trans 'Primary Users' %}

  • Visually impaired students.
  • Students with long-term neurological or musculoskeletal conditions (cerebral palsy, Muscular dystrophy etc.)
  • Candidates unable to write due to Fractures, hand injuries or similar medical conditions temporarily.
  • Slow writers, learners with dysgraphia, and users who prefer voice-based interaction.

{% trans 'Secondary Beneficiaries' %}

  • Educational institutions and examination authorities seekingtransparent, digitized examination workflows.
  • Educators and evaluators seeking standardized, inclusive assessment mechanisms or even institutions.
  • Candidates who require the writing examination in a regional language medium.

{% trans 'Frequently asked questions (FAQs)' %}

{% trans 'What is Sahayak Writer?' %}
{% blocktrans %}Sahayak Writer is a speech-based examination system that allows you to listen to questions and answer them using your voice. Your spoken answers are automatically converted into written text.{% endblocktrans %}
{% trans 'Who can use this system?' %}
{% trans 'You can use Sahayak Writer if you' %}:
  • {% trans 'Visually impaired students who cannot read printed questions.' %}
  • {% trans 'Students with motor disabilities that make writing difficult.' %}
  • {% trans 'Students with temporary injuries (e.g., fractured hand) who cannot write.' %}
  • {% trans 'Students with dysgraphia or slow writing speed.' %}
  • {% trans 'Anyone who prefers speaking over writing for exams.' %}
{% trans 'What problem does Sahayak Writer solve?' %}
{% blocktrans %}It removes dependency on human scribes and enables independent, equitable examination writing for visually impaired and motor-impaired candidates, while also supporting temporary medical cases.{% endblocktrans %}
{% trans 'Can I check or correct my answers?' %}
{% blocktrans %}Yes. The system reads back your typed response using text-to-speech. You can review, edit, and confirm your answer before submission.{% endblocktrans %}
{% trans 'How do I answer questions?' %}
{% blocktrans %}You listen to the question through headphones and speak your answer clearly into a microphone. The system converts your speech into text instantly.{% endblocktrans %}
{% trans 'Do I need computer skills to use it?' %}
{% blocktrans %}No. The interface is simple and guided. Minimal training is required before the exam.{% endblocktrans %}
{% trans 'What infrastructure is required?' %}
{% blocktrans %}Standard computers or laptops with headsets and microphones are sufficient. For large-scale deployment, dedicated ASR/TTS server configurations can be implemented.{% endblocktrans %}
{% trans 'Can it reduce administrative burden?' %}
{% blocktrans %}Yes. It eliminates scribe management, reduces approval delays, and standardizes accommodation processes.{% endblocktrans %}
{% trans 'How secure is the system?' %}
{% blocktrans %}The system operates in a controlled examination environment with secure recording, answer storage, and audit capability to maintain academic integrity.{% endblocktrans %}
